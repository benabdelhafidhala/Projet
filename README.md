# Simple Task Manager

A simple, beginner-friendly web application combining concepts from:
- **TP1-GitHub**: Clean folder structure and documentation
- **tp-formulaire**: HTML form with JavaScript validation
- **TP3-todo_list**: Dynamic DOM list with Add, Edit, Delete, and Filter
- **TP4_Debugging**: Clear `console.log` traces, `try/catch`, and modular JS files
- **TP5**: `localStorage` persistence so tasks stay saved after refreshing

## Project Structure

- `index.html` — Page layout (form + task list)
- `css/style.css` — Clean styling
- `js/storage.js` — Saves and loads tasks using `localStorage`
- `js/form.js` — Reads, validates, and resets the form (handles Add & Edit modes)
- `js/app.js` — Main logic (`addTask`, `updateTask`, `deleteTask`, `toggleTask`, `renderTasks`)

## How to Run

Open `index.html` directly in any web browser. No server or installation needed.
